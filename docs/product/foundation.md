# StylistTG: Product Foundation

## Архитектура
Продукт строится вокруг сущности "Аккаунт" (Accounts-first SaaS).
Главная задача системы — управление множеством Telegram-аккаунтов, поддержание их "здоровья" (Safety & Risk) и выполнение фоновых задач.

## Структура интерфейса
1. **SaaS Control Center (Home)**
   - `/home` — единый пульт управления. Здесь выводятся сводки по здоровью аккаунтов, активные задачи, системный статус и быстрые действия.

2. **Accounts Platform**
   - `/accounts` — таблица всех аккаунтов.
   - Поддерживает Saved Views (Все, Готовы, Высокий риск), фильтрацию и поиск.
   - Массовые действия (Обновить риск, Аудит) доступны из `AccountsTableToolbar`.

3. **Account Workspace 2.0**
   - `/accounts/:accountId` — детальное рабочее пространство конкретного аккаунта.
   - Состоит из вкладок (AnimatedTabs):
     - **Профиль**: управление именем, юзернеймом, био (работает через `@tanstack/react-form`), аватаркой.
     - **Истории**: ручная загрузка фото и видео.
     - **Музыка**: управление голосовыми профилями.
     - **Прокси**: привязка и проверка прокси (изолированно).
     - **Задачи**: лог операций для данного аккаунта.
     - **Риск и аудит**: детальная сводка по Health Status, причины риска, кулдауны и история аудита.

4. **Add Accounts 2.0**
   - Единый интерфейс для добавления аккаунтов с табами:
     - **Один аккаунт**: пошаговый SessionWizard.
     - **Список номеров**: добавление через текстовое поле.
     - **Импорт пакета**: загрузка `.zip` / `.json` сессий.

## Motion & UI Foundation
- Все переходы между страницами и вкладками используют `motion/react` (AnimatedPage, AnimatedTabs, AnimatedDialog).
- Учитываются настройки системной анимации пользователя (`reducedMotion="user"`).

## Raw Enum Protection
- В интерфейсе строго запрещено использовать системные идентификаторы бэкенда.
- Все статусы (account_state, proxy_status, risk_level, risk_reasons) проходят через словари `uiLabels.ts` для локализации на русский язык.
- Написаны тесты, гарантирующие отсутствие "утечек" сырых enum в UI.
