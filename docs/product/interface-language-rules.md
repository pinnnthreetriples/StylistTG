# Interface Language Rules

## Russian Product Language

All primary flows use Russian labels, descriptions, buttons, empty states and errors.

Use product labels instead of raw backend values:

- `ready` -> `Готов`
- `unknown` -> `Неизвестно`
- `failed` -> `Проблема`
- `low` -> `Низкий`
- `medium` -> `Средний`
- `high` -> `Высокий`
- `critical` -> `Критический`
- `mock` -> `Безопасный mock-режим`

## Technical Terms

Technical terms are allowed only when the user intentionally opens advanced diagnostics. Even there, sensitive values must stay hidden.
