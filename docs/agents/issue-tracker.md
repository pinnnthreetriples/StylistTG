# Issue Tracker

StylistTG tracks project work in GitHub Issues for `pinnnthreetriples/StylistTG`.

The StylistTG Development project board is the source of truth for active
work: https://github.com/users/pinnnthreetriples/projects/1. See
`docs/agents/project-board.md` before creating, changing, or executing
issue/PR work.

Use GitHub issues for PRDs, implementation issues, triage output, and follow-up work created by project skills such as `/to-prd` and `/to-issues`.

Before creating or changing issues:

- Check whether a relevant issue already exists.
- Use the agent-ready issue template for work intended for AI coding agents.
- Keep issue scope small enough for one focused PR whenever possible.
- Add or update the project board fields: `Priority`, `Type`, and `Area`.
- Use the repository's existing labels and milestones when available.
- Do not push branches or create production-like changes without explicit user approval.
