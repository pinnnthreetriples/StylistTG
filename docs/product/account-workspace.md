# Account Workspace 2.0

## Обзор
Рабочее пространство аккаунта (`/accounts/$accountId`) — это детальный интерфейс управления конкретной учетной записью Telegram. В версии 2.0 интерфейс разделен на функциональные вкладки для повышения удобства.

## Разделы (Вкладки)

### 1. Профиль
- **Управление**: Имя, Фамилия, Юзернейм, Био.
- **Технологии**: Работает на `@tanstack/react-form`.
- **Особенности**:
  - Валидация длины Bio (до 70 символов).
  - Индикация "грязных" полей (Dirty Dots) относительно текущего состояния в Telegram.
  - Управление аватаром (загрузка/удаление).

### 2. Истории
- Просмотр текущих активных историй.
- Загрузка новых фото и видео историй.
- Управление настройками приватности для каждой истории.

### 3. Музыка
- Управление аудио-статусом профиля.
- Загрузка новых треков и удаление существующих.

### 4. Прокси
- Настройка индивидуального прокси для аккаунта.
- Проверка работоспособности прокси в реальном времени.
- Поддержка SOCKS5 и HTTP(S).

### 5. Задачи
- Лог текущих и прошлых задач, специфичных для этого аккаунта.
- Статус выполнения в реальном времени.

### 6. Риск и аудит
- Детальная сводка безопасности.
- Список причин риска (Risk Reasons).
- Управление кулдаунами и Safety Gate.
- Полный журнал аудита изменений.

## Дизайн
Используются `AnimatedTabs` для бесшовного переключения между разделами без перезагрузки страницы. Все изменения профиля требуют подтверждения через глобальный `StickyActionBar`.
