# UI Copy & Russian Localization

## Принципы
1. **Никакого английского в основном интерфейсе**: Все кнопки, заголовки и подсказки должны быть на русском.
2. **Тональность (Tone of Voice)**: Профессиональный, сдержанный, но понятный (SaaS-стиль).
3. **Единообразие**: Используются стандартные термины (например, "Задача" вместо "Операция", "Аккаунт" вместо "Учетка").

## Словари (uiLabels.ts)
Все переводы централизованы в `apps/dashboard/src/lib/uiLabels.ts`. Это позволяет:
- Быстро менять формулировки во всем приложении.
- Гарантировать отсутствие сырых Enums в UI.
- Легко добавить новые языки в будущем.

## Правила именования
- Кнопки действий: инфинитив ("Сохранить", "Удалить", "Добавить").
- Заголовки страниц: существительные ("Аккаунты", "Настройки").
- Сообщения об успехе: прошедшее время ("Изменения сохранены", "Задача создана").
